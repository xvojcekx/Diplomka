Jak fungují jednotlivé algoritmy

Princip

Kruskalův algoritmus hledá minimální kostru (Minimum Spanning Tree) v neorientovaném souvislém ohodnoceném grafu. Kostra je podgraf, který spojuje všechny uzly s minimální celkovou váhou hran a neobsahuje cykly.

Postup krok za krokem
  1. Seřaď všechny hrany grafu vzestupně podle váhy
  2. Inicializuj datovou strukturu Union-Find — každý uzel je vlastní komponenta
  3. Iteruj přes seřazené hrany (od nejlehčí):
    • Pokud oba konce hrany patří do různých komponent → hranu PŘIJMI a slučí komponenty
    • Pokud jsou oba konce ve stejné komponentě → hranu ZAMÍTNI (vznikl by cyklus)
  4. Konec — jakmile máme n-1 hran (kde n = počet uzlů)
Časová složitost

O(E log E) — kde E je počet hran (dominuje řazení hran)

Kdy použít

Ideální pro řídké grafy (málo hran). Funguje pouze pro neorientované souvislé grafy.

Pseudokód
{% raw %} 
KRUSKAL(G):
  MST = ∅
  seřaď hrany G dle váhy
  inicializuj Union-Find

  pro každou hranu (u, v, w):
    pokud FIND(u) ≠ FIND(v):
      MST = MST ∪ {(u, v)}
      UNION(u, v)

  vrať MST
{% endraw %}

Princip

Borůvkův algoritmus (také Borůvka-Sollin) je dalším způsobem hledání minimální kostry. Na rozdíl od Kruskala, který řadí hrany globálně, Borůvkův algoritmus pracuje paralelně po komponentách.

Postup krok za krokem
  1. Inicializuj — každý uzel je samostatná komponenta
  2. Opakuj dokud existuje více než 1 komponenta:
    • Pro každou komponentu najdi nejlevnější hranu, která vede do jiné komponenty
    • Všechny takto nalezené hrany PŘIJMI a slouč příslušné komponenty
  3. Konec — všechny uzly jsou v jedné komponentě
Časová složitost

O(E log V) — kde E = hrany, V = uzly

Rozdíl oproti Kruskalovi

Borůvka nečeká na globální řazení hran, místo toho v každé iteraci každá komponenta vybere svou nejlevnější hranu. Může přidat více hran najednou. Je historicky nejstarší algoritmus pro MST (1926, Brno!).

Pseudokód
{% raw %} 
BORŮVKA(G):
  MST = ∅
  komponenty = {{v} pro v ∈ V}

  dokud |komponenty| > 1:
    pro každou komponentu C:
      najdi nejlevnější hranu (u,v)
        kde u∈C a v∉C
      MST = MST ∪ {(u, v)}
      slouč C s komponentou v

  vrať MST
{% endraw %}

Princip

Dijkstrův algoritmus hledá nejkratší cestu z jednoho zdrojového uzlu do cílového (nebo do všech ostatních). Funguje na grafech s nezápornými vahami.

Postup krok za krokem
  1. Inicializuj — vzdálenost zdroje = 0, všech ostatních = ∞
  2. Vlož zdroj do prioritní fronty (min-heap)
  3. Opakuj dokud fronta není prázdná:
    • Vyjmi uzel u s nejmenší vzdáleností
    • Pro každého souseda v uzlu u:
      • Spočítej novou vzdálenost: dist[u] + w(u,v)
      • Pokud je menší než dist[v] → aktualizuj (relakace)
      • Jinak → přeskoč
  4. Rekonstrukce cesty zpětným průchodem přes předchůdce
Časová složitost

O((V + E) log V) — s binární haldou

Omezení (Záporné váhy)
Kritické chování při záporných mírách

Dijkstrův algoritmus nefunguje správně pro grafy se zápornými vahami hran. Základní princip algoritmu stojí na faktu, že jakmile uzel vybere z prioritní fronty (tzn. ho uzavře/dokončí), striktně předpokládá, že už do něj neexistuje žádná kratší cesta. Pokud ale graf obsahuje zápornou hranu, mohlo by přidání dalšího kroku paradoxně celkovou vzdálenost zmenšit a zlevnit cestu do dříve uzavřeného uzlu!

V generátoru naší apikace si to můžete snadno nasimulovat povolením záporných vah (např. do -10). Při vizualizaci algoritmu pak zřetelně uvidíte, jak Dijkstra vyhodnotí cestu sub-optimálně – nevšimne si, že oklikou skrze zápornou hranu to vyšlo lépe. Jestliže navíc graf obsahuje záporný cyklus (cesta do kruhu se záporným součtem), ztratilo by hledání nejkratší trasy úplně matematický smysl. V reálné praxi se pro zpracování jakýchkoliv záporných hran používá robustnější Bellman-Fordův algoritmus.

Pseudokód
{% raw %} 
DIJKSTRA(G, zdroj, cíl):
  dist[v] = ∞ pro ∀v ∈ V
  dist[zdroj] = 0
  prev[v] = null
  PQ = {(0, zdroj)}

  dokud PQ není prázdná:
    (d, u) = PQ.vyber_min()
    pokud u == cíl: KONEC

    pro (u, v, w) ∈ hrany(u):
      pokud d + w < dist[v]:
        dist[v] = d + w
        prev[v] = u
        PQ.vlož(d+w, v)

  rekonstruuj cestu z prev[]
{% endraw %}

Princip

BFS (Breadth-First Search) systematicky prochází graf po vrstvách — nejprve navštíví všechny sousedy aktuálního uzlu, pak sousedy sousedů atd. Používá frontu (FIFO).

Postup krok za krokem
  1. Vlož počáteční uzel do fronty a označ jako navštívený
  2. Opakuj dokud fronta není prázdná:
    • Vyjmi uzel u z fronty
    • Pro každého souseda v:
      • Pokud v nebyl navštíven → označ a přidej do fronty
      • Jinak → přeskoč
Časová složitost

O(V + E)

Použití

Nejkratší cesta v neohodnoceném grafu, testování souvislosti, hledání komponent.

Pseudokód
{% raw %} 
BFS(G, start):
  fronta = [start]
  navštíveno = {start}

  dokud fronta není prázdná:
    u = fronta.vyber()
    pro (u, v) ∈ hrany(u):
      pokud v ∉ navštíveno:
        navštíveno += {v}
        fronta.přidej(v)
{% endraw %}

Princip

DFS (Depth-First Search) prochází graf do hloubky — jde co nejdále jedním směrem, pak se vrací (backtracking). Používá zásobník (LIFO) nebo rekurzi.

Postup krok za krokem
  1. Vlož počáteční uzel na zásobník
  2. Opakuj dokud zásobník není prázdný:
    • Vyjmi uzel u ze zásobníku
    • Pokud u nebyl navštíven:
      • Označ jako navštívený
      • Pro každého souseda v: pokud nebyl navštíven → vlož na zásobník
Časová složitost

O(V + E)

Použití

Detekce cyklů, topologické třídění, hledání artikulací a mostů, řešení bludišť.

Rozdíl oproti BFS

BFS prochází po vrstvách (fronta), DFS jde co nejhlouběji (zásobník). BFS najde nejkratší cestu v neohodnoceném grafu, DFS ne.

Pseudokód
{% raw %} 
DFS(G, start):
  zásobník = [start]
  navštíveno = {}

  dokud zásobník není prázdný:
    u = zásobník.vyber()
    pokud u ∉ navštíveno:
      navštíveno += {u}
      pro (u, v) ∈ hrany(u):
        pokud v ∉ navštíveno:
          zásobník.vlož(v)
{% endraw %}
