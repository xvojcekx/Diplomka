Jak fungují jednotlivé algoritmy

Princip

Kruskalův algoritmus hledá minimální kostru (Minimum Spanning Tree) v neorientovaném souvislém ohodnoceném grafu. Kostra je podgraf, který spojuje všechny uzly s minimální celkovou váhou hran a neobsahuje cykly.

Postup krok za krokem
  1. Seřaď všechny hrany grafu vzestupně podle váhy
  2. Inicializuj datovou strukturu Union-Find — každý uzel je vlastní komponenta
  3. Iteruj přes seřazené hrany (od nejlehčí):
    • Pokud oba konce hrany patří do různých komponent → hranu PŘIJMI a slučí komponenty
    • Pokud jsou oba konce ve stejné komponentě → hranu ZAMÍTNI (vznikl by cyklus)
  4. Konec — jakmile máme n-1 hran (kde n = počet uzlů)
Časová složitost

O(E log E) — kde E je počet hran (dominuje řazení hran)

Kdy použít

Ideální pro řídké grafy (málo hran). Funguje pouze pro neorientované souvislé grafy.

Pseudokód
{% raw %} 
KRUSKAL(G):
  MST = ∅
  seřaď hrany G dle váhy
  inicializuj Union-Find

  pro každou hranu (u, v, w):
    pokud FIND(u) ≠ FIND(v):
      MST = MST ∪ {(u, v)}
      UNION(u, v)

  vrať MST
{% endraw %}

Princip

Borůvkův algoritmus (také Borůvka-Sollin) je dalším způsobem hledání minimální kostry. Na rozdíl od Kruskala, který řadí hrany globálně, Borůvkův algoritmus pracuje paralelně po komponentách.

Postup krok za krokem
  1. Inicializuj — každý uzel je samostatná komponenta
  2. Opakuj dokud existuje více než 1 komponenta:
    • Pro každou komponentu najdi nejlevnější hranu, která vede do jiné komponenty
    • Všechny takto nalezené hrany PŘIJMI a slouč příslušné komponenty
  3. Konec — všechny uzly jsou v jedné komponentě
Časová složitost

O(E log V) — kde E = hrany, V = uzly

Rozdíl oproti Kruskalovi

Borůvka nečeká na globální řazení hran, místo toho v každé iteraci každá komponenta vybere svou nejlevnější hranu. Může přidat více hran najednou. Je historicky nejstarší algoritmus pro MST (1926, Brno!).

Pseudokód
{% raw %} 
BORŮVKA(G):
  MST = ∅
  komponenty = {{v} pro v ∈ V}

  dokud |komponenty| > 1:
    pro každou komponentu C:
      najdi nejlevnější hranu (u,v)
        kde u∈C a v∉C
      MST = MST ∪ {(u, v)}
      slouč C s komponentou v

  vrať MST
{% endraw %}

Princip

Dijkstrův algoritmus hledá nejkratší cestu z jednoho zdrojového uzlu do cílového (nebo do všech ostatních). Funguje na grafech s nezápornými vahami.

Postup krok za krokem
  1. Inicializuj — vzdálenost zdroje = 0, všech ostatních = ∞
  2. Vlož zdroj do prioritní fronty (min-heap)
  3. Opakuj dokud fronta není prázdná:
    • Vyjmi uzel u s nejmenší vzdáleností
    • Pro každého souseda v uzlu u:
      • Spočítej novou vzdálenost: dist[u] + w(u,v)
      • Pokud je menší než dist[v] → aktualizuj (relakace)
      • Jinak → přeskoč
  4. Rekonstrukce cesty zpětným průchodem přes předchůdce
Časová složitost

O((V + E) log V) — s binární haldou

Omezení (Záporné váhy)
Kritické chování při záporných mírách

Dijkstrův algoritmus nefunguje správně pro grafy se zápornými vahami hran. Základní princip algoritmu stojí na faktu, že jakmile uzel vybere z prioritní fronty (tzn. ho uzavře/dokončí), striktně předpokládá, že už do něj neexistuje žádná kratší cesta. Pokud ale graf obsahuje zápornou hranu, mohlo by přidání dalšího kroku paradoxně celkovou vzdálenost zmenšit a zlevnit cestu do dříve uzavřeného uzlu!

V generátoru naší apikace si to můžete snadno nasimulovat povolením záporných vah (např. do -10). Při vizualizaci algoritmu pak zřetelně uvidíte, jak Dijkstra vyhodnotí cestu sub-optimálně – nevšimne si, že oklikou skrze zápornou hranu to vyšlo lépe. Jestliže navíc graf obsahuje záporný cyklus (cesta do kruhu se záporným součtem), ztratilo by hledání nejkratší trasy úplně matematický smysl. V reálné praxi se pro zpracování jakýchkoliv záporných hran používá robustnější Bellman-Fordův algoritmus.

Pseudokód
{% raw %} 
DIJKSTRA(G, zdroj, cíl):
  dist[v] = ∞ pro ∀v ∈ V
  dist[zdroj] = 0
  prev[v] = null
  PQ = {(0, zdroj)}

  dokud PQ není prázdná:
    (d, u) = PQ.vyber_min()
    pokud u == cíl: KONEC

    pro (u, v, w) ∈ hrany(u):
      pokud d + w < dist[v]:
        dist[v] = d + w
        prev[v] = u
        PQ.vlož(d+w, v)

  rekonstruuj cestu z prev[]
{% endraw %}

Princip

BFS (Breadth-First Search) systematicky prochází graf po vrstvách — nejprve navštíví všechny sousedy aktuálního uzlu, pak sousedy sousedů atd. Používá frontu (FIFO).

Postup krok za krokem
  1. Vlož počáteční uzel do fronty a označ jako navštívený
  2. Opakuj dokud fronta není prázdná:
    • Vyjmi uzel u z fronty
    • Pro každého souseda v:
      • Pokud v nebyl navštíven → označ a přidej do fronty
      • Jinak → přeskoč
Časová složitost

O(V + E)

Použití

Nejkratší cesta v neohodnoceném grafu, testování souvislosti, hledání komponent.

Pseudokód
{% raw %} 
BFS(G, start):
  fronta = [start]
  navštíveno = {start}

  dokud fronta není prázdná:
    u = fronta.vyber()
    pro (u, v) ∈ hrany(u):
      pokud v ∉ navštíveno:
        navštíveno += {v}
        fronta.přidej(v)
{% endraw %}

Princip

DFS (Depth-First Search) prochází graf do hloubky — jde co nejdále jedním směrem, pak se vrací (backtracking). Používá zásobník (LIFO) nebo rekurzi.

Postup krok za krokem
  1. Vlož počáteční uzel na zásobník
  2. Opakuj dokud zásobník není prázdný:
    • Vyjmi uzel u ze zásobníku
    • Pokud u nebyl navštíven:
      • Označ jako navštívený
      • Pro každého souseda v: pokud nebyl navštíven → vlož na zásobník
Časová složitost

O(V + E)

Použití

Detekce cyklů, topologické třídění, hledání artikulací a mostů, řešení bludišť.

Rozdíl oproti BFS

BFS prochází po vrstvách (fronta), DFS jde co nejhlouběji (zásobník). BFS najde nejkratší cestu v neohodnoceném grafu, DFS ne.

Pseudokód
{% raw %} 
DFS(G, start):
  zásobník = [start]
  navštíveno = {}

  dokud zásobník není prázdný:
    u = zásobník.vyber()
    pokud u ∉ navštíveno:
      navštíveno += {u}
      pro (u, v) ∈ hrany(u):
        pokud v ∉ navštíveno:
          zásobník.vlož(v)
{% endraw %}

Princip

Bellmanův–Fordův algoritmus hledá nejkratší cesty z jednoho výchozího vrcholu do všech ostatních vrcholů i v grafech, které obsahují záporně ohodnocené hrany. Na rozdíl od hladového Dijkstrova algoritmu postupuje metodou dynamického programování — opakovaně relaxuje všechny hrany grafu.

Postup krok za krokem
  1. Inicializuj — vzdálenost zdroje dist[zdroj] = 0, ostatních vrcholů ∞
  2. Proveď |V| − 1 fází (iterací):
    • V každé fázi projdi všechny hrany (u, v, w) ∈ E
    • Pokud dist[u] + w < dist[v] → proveď relaxaci dist[v] = dist[u] + w a ulož předchůdce prev[v] = u
  3. Kontrola záporného cyklu (|V|. fáze): Pokud lze ještě v |V|-tém průchodu některou hranu zkrátit, graf obsahuje dosažitelný záporný cyklus a nejkratší cesta není konečná.
Časová složitost

O(V · E) — pomalejší než Dijkstra, ale univerzální pro záporné váhy.

Pseudokód
{% raw %} 
BELLMAN_FORD(G, zdroj):
  dist[v] = ∞ pro ∀v ∈ V
  dist[zdroj] = 0

  pro i = 1 do |V| - 1:
    pro každou (u, v, w) ∈ E:
      pokud dist[u] + w < dist[v]:
        dist[v] = dist[u] + w
        prev[v] = u

  pro každou (u, v, w) ∈ E:
    pokud dist[u] + w < dist[v]:
      chyba "Záporný cyklus"

  vrať dist[], prev[]
{% endraw %}

Princip

Řeší úlohu maximálního toku v dopravní síti ze zdroje s do stoku t, kde nezáporné váhy orientovaných hran představují kapacity c(u, v). Edmondsova–Karpova varianta hledá zlepšující (augmentační) cesty v reziduální síti pomocí prohledávání do šířky (BFS).

Postup krok za krokem
  1. Nulový výchozí tok — na všech hranách nastav f(u, v) = 0
  2. Dokud existuje zlepšující cesta ze zdroje s do stoku t v reziduální síti G_f:
    • Najdi nejkratší zlepšující cestu pomocí BFS
    • Urči její úzké hrdlo (minimum z reziduálních kapacit na cestě): Δ = min c_f(e)
    • Zvyš tok podél cesty o hodnotu Δ a aktualizuj reziduální kapacity
  3. Minimální s–t řez: Množina vrcholů S dosažitelných ze zdroje v konečné reziduální síti definuje minimální řez (S, V \ S). Podle Věty o maximálním toku a minimálním řezu se součet kapacit hran vedoucích z S do T přesně rovná velikosti maximálního toku.
Časová složitost

O(V · E²) — pro Edmondsovu–Karpovu implementaci pomocí BFS.

Pseudokód
{% raw %} 
EDMONDS_KARP(G, s, t):
  f(u, v) = 0 pro ∀(u, v) ∈ E
  max_tok = 0

  dokud cesta = BFS_REZIDUALNI(G_f, s, t):
    delta = min { c_f(u, v) : (u,v) ∈ cesta }
    pro každou (u, v) ∈ cesta:
      f(u, v) += delta
      f(v, u) -= delta
    max_tok += delta

  S = dosažitelné vrcholy z s v G_f
  T = V \ S
  vrať max_tok, řez (S, T)
{% endraw %}

Princip

Topologické uspořádání orientovaného acyklického grafu (DAG) je lineární pořadí všech vrcholů takové, že pro každou orientovanou hranu u → v leží vrchol u v pořadí před vrcholem v. V praxi modeluje harmonogram závislých činností či prerekvizit.

Postup krok za krokem
  1. Spočítej vstupní stupně deg⁻(v) pro všechny vrcholy grafu
  2. Vlož do fronty všechny vrcholy s nulovým vstupním stupněm deg⁻(v) = 0 (činnosti bez prerekvizit)
  3. Opakuj dokud fronta není prázdná:
    • Vyjmi vrchol u z fronty a přidej jej na konec topologického pořadí
    • Pro každého následovníka v po hraně u → v sniž deg⁻(v) o 1; klesne-li na 0, vlož v do fronty
  4. Pokud výstup neobsahuje všech |V| vrcholů, graf obsahuje orientovaný cyklus a topologické uspořádání neexistuje.
Časová složitost

O(V + E)

Pseudokód
{% raw %} 
KAHN_TOPOSORT(G):
  in_deg[v] = vstupní stupeň v
  Q = { v ∈ V : in_deg[v] == 0 }
  pořadí = []

  dokud Q není prázdná:
    u = Q.vyber()
    pořadí.přidej(u)
    pro (u, v) ∈ hrany(u):
      in_deg[v] -= 1
      pokud in_deg[v] == 0:
        Q.vlož(v)

  pokud |pořadí| < |V|:
    chyba "Graf obsahuje cyklus"
  vrať pořadí
{% endraw %}

Princip

Strukturální analýza zranitelnosti sítě odhaluje kritické prvky, jejichž výpadek způsobí rozpad grafu:

  • Most (bridge): Hrana e ∈ E, jejíž odebrání zvýší počet souvislých komponent grafu.
  • Artikulace (cut vertex): Vrchol v ∈ V, jehož odebrání spolu s incidentními hranami zvýší počet souvislých komponent.
  • Silně souvislé komponenty (SCC): V orientovaném grafu maximální podmnožiny vrcholů, mezi nimiž existuje orientovaná cesta v obou směrech.
Princip detekce (DFS časy disc a low)

Při průchodu do hloubky (DFS) se pro každý vrchol u zaznamenává čas objevení disc[u] a nejmenší čas low[u] dosažitelný z podstromu vrcholu u pomocí nejvýše jedné zpětné hrany. Platí-li pro stromovou hranu (u, v) nerovnost low[v] > disc[u], neexistuje z podstromu v žádná zpětná hrana nad u a hrana (u, v) je mostem.

Časová složitost

O(V + E) — jediný průchod DFS.

Pseudokód (Hledání mostů)
{% raw %} 
DFS_MOSTY(u, rodič):
  disc[u] = low[u] = ++čas
  pro v ∈ sousedé(u):
    pokud v == rodič: pokračuj
    pokud v nebyl navštíven:
      DFS_MOSTY(v, u)
      low[u] = min(low[u], low[v])
      pokud low[v] > disc[u]:
        MOST(u, v)
    jinak:
      low[u] = min(low[u], disc[v])
{% endraw %}

1. Barvení vrcholů (Welshův–Powellův algoritmus)

Přiřazuje vrcholům barvy tak, aby žádné dva sousední vrcholy neměly stejnou barvu. Heuristika seřadí vrcholy sestupně podle stupně deg(v) a postupně každému vrcholu přiřadí nejmenší dostupnou barvu, kterou nemá žádný jeho soused. Poskytuje horní odhad chromatického čísla χ(G).

2. Eulerovský tah a kružnice (Hierholzerův algoritmus)

Eulerovský tah projde každou hranu grafu právě jednou. V souvislém neorientovaném grafu existuje tehdy a jen tehdy, je-li počet vrcholů lichého stupně roven 0 (Eulerovská kružnice — uzavřený tah) nebo 2 (otevřený Eulerovský tah začínající v jednom a končící ve druhém vrcholu lichého stupně).

3. Hamiltonovská cesta a kružnice

Hamiltonovská cesta navštíví každý vrchol grafu právě jednou. Na rozdíl od Eulerovských úloh jde o NP-úplný problém, který aplikace pro výukové grafy řeší exaktním prohledáváním s návratem (backtracking).

Přehled podmínek a složitostí
{% raw %} 
WELSH_POWELL(G):
  seřaď vrcholy sestupně dle deg(v)
  pro každý uzel u:
    barva[u] = min { c ≥ 1 :
      ∀v ∈ sousedé(u): barva[v] ≠ c }

EULERŮV_TAH(G):
  liché = { v ∈ V : deg(v) mod 2 == 1 }
  kružnice ⇔ |liché| == 0
  tah      ⇔ |liché| == 2
  Složitost: O(V + E)

HAMILTONOVA_CESTA(G):
  Backtracking přes permutace V
  Složitost: O(V!) v nejhorším případě
